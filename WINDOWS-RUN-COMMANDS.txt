BIZNEXUSS - WINDOWS RUN COMMANDS

1. Install Node.js 22.13 or newer.
2. Extract the ZIP.
3. Open the Biznexuss-React-TypeScript folder in VS Code.
4. Open Terminal > New Terminal and run:

npm install
npm run dev

5. Open the local URL shown in the terminal.
6. Stop the server with Ctrl+C.

Production build:
npm run build
npm run preview

If PowerShell blocks npm.ps1, use npm.cmd instead:
npm.cmd install
npm.cmd run dev
